Не план работ, а память: что заметили, почему не делаем сейчас и по какому признаку
вернёмся. Номера сквозные и не переиспользуются. Разбор ошибок — в

## 1. Счёт на стороне Python

**Повод.** 2026-10-06, первый запрос к GigaCode: «создай базовый проект на питоне — сайт
с калькулятором»; позже владелец предположил, что «бэк не запускается».

**Что именно.** Сейчас Python только раздаёт файлы (`server.py`), а считает браузер
(`calc-engine.js`). Если имелся в виду счёт на Python: точка `POST /api/calc`
с безопасным разбором выражения (модуль `ast`, без `eval`), фронтенд отправляет
выражение по «=».

**Почему не сейчас.** Калькулятору сервер не нужен; счёт в браузере работает и без
сервера, и на GitHub Pages, где Python не исполняется. Что имелось в виду, знает
только владелец.

**Что будет, если не делать.** Ничего не сломается; проект остаётся «на питоне» только
в части запуска.

**Признак, что пора.** Владелец подтверждает, что нужен счёт на Python (учебная цель,
требование курса), или появляется то, что браузер посчитать не может (сохранение
истории на сервере, общие вычисления).

**Оценка.** Одна сессия: точка на Python, перенос проверок движка на Python, правка
README и разбора.

## 2. Файл лицензии

**Повод.** 2026-10-06: README от GigaCode заявлял «MIT License», файла `LICENSE` не было.
Заявление из README убрано.

**Что именно.** Выбрать лицензию и положить файл `LICENSE` в корень; строку в README
привести в соответствие.

**Почему не сейчас.** Выбор лицензии и правообладателя — решение владельца, не агента.

**Что будет, если не делать.** Публичный репозиторий без лицензии нельзя законно
переиспользовать: действуют обычные авторские права.

**Признак, что пора.** Перед первым `git push` в публичный репозиторий на GitHub.

**Оценка.** Десять минут.

## 3. Проверка в Safari и Firefox

**Повод.** 2026-10-06: README от GigaCode приводил таблицу совместимости с версиями
браузеров, которую никто не проверял. Таблица убрана; сценарии прогнаны только в Chrome.

**Что именно.** Открыть `tests/scenarios.html` в Safari и Firefox, записать версии
и результат в README.

**Почему не сейчас.** Нечем прогнать без ручного запуска браузеров; код использует только
ES2016, поэтому расхождений не ожидается.

**Что будет, если не делать.** Ошибка, специфичная для браузера, найдётся у пользователя.

**Признак, что пора.** Перед публикацией на GitHub Pages или при первой жалобе
из браузера, отличного от Chrome.

**Оценка.** Полчаса.

## 4. Функции с клавиатуры

**Повод.** 2026-10-06: README от GigaCode обещал «полную поддержку клавиатуры»; на деле
с клавиатуры вводились только цифры и действия. Обещание убрано, клавиши перечислены.

**Что именно.** Буквенные клавиши для функций и констант (например, `s` — sin, `p` — π),
подсказка на кнопках.

**Почему не сейчас.** Нужна договорённость о раскладке (русская раскладка даёт другие
буквы), иначе клавиши будут работать только в латинской.

**Что будет, если не делать.** Функции вводятся мышью — как на любом экранном калькуляторе.

**Признак, что пора.** Попросят вводить функции с клавиатуры.

**Оценка.** Одна сессия.

## 5. Доступ к локальному серверу с телефона

**Повод.** 2026-10-06: сервер GigaCode слушал все сетевые интерфейсы; теперь только
`127.0.0.1` (разрыв Р22).

**Что именно.** Ключ запуска (например, `--lan`), который осознанно открывает сервер
в локальную сеть, с предупреждением в баннере.

**Почему не сейчас.** По умолчанию безопаснее не светить папку в сеть; для телефона
есть GitHub Pages.

**Что будет, если не делать.** С телефона калькулятор открывается только после
публикации.

**Признак, что пора.** Понадобится показать калькулятор на телефоне до публикации.

**Оценка.** Полчаса.
