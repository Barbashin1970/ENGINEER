> Современный инженерный калькулятор, работающий прямо в браузере

## 📖 О проекте

Полнофункциональный инженерный калькулятор с красивым интерфейсом, который работает непосредственно в веб-браузере. Поддерживает как базовые, так и сложные математические операции.

## ✨ Возможности

### Базовые операции
- ➕ Сложение, вычитание, умножение, деление
- ➗ Процент (%)
- 🔢 Десятичные числа
- ⌨️ Поддержка клавиатуры

### Инженерные функции
- 📐 **Тригонометрия**: sin, cos, tan (и обратные функции)
- 📊 **Логарифмы**: log (по основанию 10), ln (натуральный)
- 🔢 **Степени**: возведение в степень (x^y), квадрат
- 📏 **Корни**: квадратный корень (√)
- 🔬 **Дополнительно**: факториал (n!), модуль (|x|), exp
- 🎯 **Константы**: π (число Пи), e (число Эйлера)

### Удобства
- 🔄 Переключение DEG/RAD (градусы/радианы)
- 🔄 Режим INV (обратные функции)
- ⌨️ Полная поддержка клавиатуры
- 📱 Адаптивный дизайн (мобильные устройства)
- 🎨 Современный тёмный интерфейс
- ⌫ Операции отмены (AC, CE, backspace)
- ➡️ Продолжение вычислений

## 🚀 Быстрый старт

### Способ 1: Двойной клик по start.command (Рекомендуется)

Просто дважды кликните по файлу `start.command` — сервер запустится автоматически, и калькулятор откроется в браузере.

```bash
# Или через терминал:
./start.command
```

### Способ 2: Через терминал

```bash
# Запуск сервера
python3 server.py

# Затем откройте: http://localhost:8080
```

### Способ 3: Открыть напрямую

Просто откройте файл `index.html` в любом современном браузере:

```bash
# macOS
open index.html

# Linux
xdg-open index.html

# Windows
start index.html
```

### Способ 4: Live Server (VS Code)

1. Установите расширение **Live Server** в VS Code
2. Откройте файл `index.html`
3. Нажмите правой кнопкой мыши → **Open with Live Server**

## 🌐 Публикация на GitHub Pages

### Шаг 1: Создайте репозиторий на GitHub

1. Перейдите на [github.com/new](https://github.com/new)
2. Введите имя репозитория (например, `engineering-calculator`)
3. Выберите **Public**
4. Нажмите **Create repository**

### Шаг 2: Загрузите файлы

```bash
# Инициализируйте Git (если ещё не сделано)
git init

# Добавьте все файлы
git add .

# Создайте первый коммит
git commit -m "Initial commit: Engineering Calculator"

# Добавьте удалённый репозиторий
git remote add origin https://github.com/ВАШ_НИК/engineering-calculator.git

# Отправьте в GitHub
git branch -M main
git push -u origin main
```

### Шаг 3: Включите GitHub Pages

1. Откройте ваш репозиторий на GitHub
2. Перейдите в **Settings** → **Pages**
3. В разделе **Source** выберите **Deploy from a branch**
4. В **Branch** выберите `main` и папку `/ (root)`
5. Нажмите **Save**

Ваш калькулятор будет доступен по адресу:
```
https://ВАШ_НИК.github.io/engineering-calculator/
```
